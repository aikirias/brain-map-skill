# Aurora Dynamics — Values

Our six operating values:

1. **Safety is the feature**
2. **Earn trust in small steps**
3. **Default to candor**
4. **Ship, then sharpen**
5. **Customer reality over internal opinion**
6. **Leave the codebase kinder**
